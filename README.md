# 🌍 ATLASX – Smart Travel Discovery Platform

ATLASX is a full-stack travel discovery web application that allows users to explore cities around the world instantly. Instead of searching through multiple websites, users can discover landmarks, hidden gems, seasonal destinations, and personalized recommendations in one interactive platform.

---

## 🚀 Features

-  **Instant City Exploration**  
  Explore landmarks, museums, nature spots, and hidden gems by city.

-  **Interactive World Map**  
  Visual city markers for intuitive geographic exploration.

-  **AI-Powered Travel Chatbot**  
  Recommends places based on destination and user-selected vibes.

-  **Seasonal Recommendations**  
  Curated destinations for spring, summer, autumn, and winter.

-  **Travel Stories**  
  User-generated stories that inspire exploration and connect travelers.

-  **Personalized Experience**  
  Like places, add them to a wishlist, mark as visited, and track activity.

-  **Smooth UI & Animations**  
  Confetti celebrations, animated transitions, and dark/light mode support.

---

## 🛠️ Tech Stack

### Frontend
- React.js  
- JavaScript (ES6+)  
- CSS3  
- WebGL (OGL.js)  
- Bootstrap Icons  

### Backend
- Node.js  
- Express.js  
- JWT Authentication  
- RESTful APIs  

### Data Persistence
- localStorage (Frontend)  
- JSON-based storage (Backend)
